Подробное описание

Класс цифрового PID-регулятора.

Реализует алгоритм автоматического регулирования в инкрементальной форме.

Регулятор рассчитывает приращение управляющего воздействия на основании текущей и двух предыдущих ошибок.

double PIDController::calculate ( double error,
double dt )

Рассчитывает новое управляющее воздействие.

Рассчитывает управляющее воздействие.

Используется инкрементальный алгоритм PID:

deltaU = Kp*(e - e1)

  • Ki*e*dt
  • Kd/dt*(e - 2*e1 + e2)
Аргументы
errorТекущая ошибка регулирования.
dtШаг дискретизации по времени.
Возвращает
Новое управляющее воздействие.
