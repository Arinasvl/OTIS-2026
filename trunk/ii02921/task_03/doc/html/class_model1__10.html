Подробное описание

Математическая модель 1.10.

Модель описывается разностным уравнением:

y(t+1) = a1*y(t) + b1*u(t) + b2*u(t-2)

В модели учитывается текущее управляющее воздействие и запаздывающее воздействие с двумя шагами задержки.
